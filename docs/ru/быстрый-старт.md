# Быстрый старт

Этот гайд проведёт вас через **Entry-уровень**: две платы ESP32-S3, ваш обычный WiFi-роутер и компьютер с edge-сервером WaveSight. С нуля до живого индикатора присутствия — примерно за 30 минут.

## Что понадобится

### Железо (~$20 + ваш компьютер)

- 2 × ESP32-S3 (DevKitC-1 или аналог, dual-core, 4+ МБ flash)
- 2 × кабеля micro-USB или USB-C
- WiFi-роутер 2.4 ГГц или 5 ГГц (подойдёт любой современный AP)
- Linux/macOS/Windows-компьютер с 4+ ГБ RAM и свободным USB-портом

### Софт

- [Rust 1.78+](https://rustup.rs)
- [ESP-IDF 5.2+](https://docs.espressif.com/projects/esp-idf/en/v5.2/esp32s3/get-started/index.html)
- [Node 20+](https://nodejs.org) и [pnpm](https://pnpm.io/installation)
- [Python 3.11+](https://www.python.org) (только для тренировки моделей, не обязательно сейчас)
- `git`

## Шаг 1 — Клонируем репо

```bash
git clone https://github.com/vladimir120307-droid/wavesight.git
cd wavesight
```

## Шаг 2 — Настраиваем прошивку

После `idf.py menuconfig` укажите в `firmware/esp32-csi-node/main/Kconfig.projbuild`:

- **WiFi SSID** — ваша домашняя сеть
- **WiFi password** — пароль
- **Server endpoint** — `ws://<ip-вашего-PC>:8080/ingest`
- **Node name** — `node-1` для первой платы, `node-2` для второй

```bash
cd firmware/esp32-csi-node
idf.py set-target esp32s3
idf.py menuconfig
```

## Шаг 3 — Прошиваем обе платы

```bash
# Первая плата (/dev/ttyUSB0 на Linux/macOS, COM3 на Windows)
idf.py -p /dev/ttyUSB0 flash monitor

# Ctrl-] чтобы выйти из монитора, когда увидите "WiFi connected, sending CSI"

# Повторить для второй платы
idf.py -p /dev/ttyUSB1 flash monitor
```

В логе должно появиться:

```
I (4321) wavesight: WiFi connected to MyHomeWiFi
I (4327) wavesight: CSI capture started, 100 frames/s
I (4399) wavesight: Server connection established
```

## Шаг 4 — Запускаем edge-сервер

```bash
cd ../../server
cargo run --release --bin wavesight -- serve --listen 0.0.0.0:8080
```

Сервер ждёт подключения CSI-потоков:

```
INFO wavesight: edge server listening on 0.0.0.0:8080
INFO csi_ingest: node-1 connected
INFO csi_ingest: node-2 connected
INFO fusion: 2-node mesh active, time sync RMS ≈ 2 μs
```

## Шаг 5 — Запускаем дашборд

В отдельном терминале:

```bash
cd dashboard
pnpm install
pnpm dev
```

Откройте `http://localhost:5173`. Через несколько секунд должно появиться:

- Две зелёные точки на карте топологии
- Живая CSI-спектрограмма для каждой ноды
- Индикатор **Присутствие**, который переключается в **обнаружено**, когда вы проходите между платами

## Шаг 6 — Калибровка

Нажмите **Калибровка** в дашборде. Стойте в комнате 30 секунд, затем выйдите на 30 секунд. WaveSight построит clutter-карту пустой комнаты — это резко повышает точность.

## Решение проблем

| Симптом | Вероятная причина | Решение |
|---|---|---|
| Нода не подключается | Неверные WiFi-данные, или сервер недоступен | `idf.py monitor`, посмотрите лог |
| Presence мигает | Недостаточная калибровка | Перекалибровать с полностью пустой комнатой |
| Красная нода в дашборде | Потеря соединения | Проверьте уровень WiFi у ноды |
| CSI rate < 100 fps | AP троттлит | Попробуйте 5 ГГц или менее загруженный 2.4 ГГц канал |
