# WaveSight honest benchmark suite

This directory contains the tooling that makes every WaveSight metric
reproducible by anyone with the right hardware and a recorded dataset.
See [ADR-004](../docs/adr/0004-honest-mode.md) for the philosophical
rationale.

## EN

### What lives here

```
eval/
├── scenarios/      # YAML descriptions of each benchmark scenario
├── ground_truth/   # RGB-D camera captures + IMU traces (gitignored bulk)
├── metrics/        # Python module that computes precision/recall/MAE
├── replay/         # Rust binary that streams a recorded session through
│                   #   the live pipeline as if it were happening now
└── REPORT_v0.1.md  # Latest publishable report (regenerated by CI)
```

### Run the suite

```bash
# Stream a recorded session through the live server:
cargo run -p eval-replay -- --session ground_truth/2026-05-23/session-01

# Compute metrics against the recorded ground truth:
python -m wavesight_eval.metrics ground_truth/2026-05-23/session-01
```

### Honest reporting rules

1. Every metric ships with an error bar.
2. Every metric ships with a per-scenario breakdown.
3. We do not publish a metric if we have not recorded a video of the
   scenario alongside the CSI capture.
4. Datasets used for evaluation are public on HuggingFace under
   `huggingface.co/datasets/wavesight/*`.

## RU

### Что здесь

```
eval/
├── scenarios/      # YAML-описания сценариев
├── ground_truth/   # Захваты RGB-D + IMU (gitignored, тяжёлые)
├── metrics/        # Python-модуль для precision/recall/MAE
├── replay/         # Rust-бинарник, проигрывает запись через live pipeline
└── REPORT_v0.1.md  # Последний публикуемый отчёт (генерится в CI)
```

### Запустить

```bash
cargo run -p eval-replay -- --session ground_truth/2026-05-23/session-01
python -m wavesight_eval.metrics ground_truth/2026-05-23/session-01
```

### Правила честной отчётности

1. Каждая метрика — с error bar.
2. Каждая метрика — с разбивкой по сценариям.
3. Не публикуем метрику, если не записали видео сценария вместе с CSI.
4. Датасеты для оценки — публичные на HuggingFace `wavesight/*`.
